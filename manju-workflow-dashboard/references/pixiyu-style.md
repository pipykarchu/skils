# 皮玺玉风格

Use this as a dashboard style preset for 漫剧 production workflows.

## Visual Identity

- Palette: ink black, dark jade green, warm muted gold, cyan-gray, faded red only for warnings.
- Texture: subtle film grain, paper/ink feeling, low-glow lines.
- Mood: cinematic, grounded, restrained, folk-horror adjacent.
- Layout: dense workflow board, not a landing page.
- Typography: Microsoft YaHei / PingFang SC / Noto Sans SC; code uses Consolas.

## Components

- Hero should be compact and functional.
- Use cards for stages, checks, and platform groups.
- Use tables for platform decisions and acceptance criteria.
- Use colored pills for status: Input, Tool, Confirm, Fail, Output.
- Keep border radius around 8-10px.

## Avoid

- Do not use SaaS gradient hero style.
- Do not use decorative orb backgrounds.
- Do not use oversized marketing slogans.
- Do not overuse purple/blue gradients.
- Do not hide workflow detail behind abstract icons.

## Prompt Style For Generated Visuals

When generating images for the dashboard or its workflow assets, append:

```text
皮玺玉风格，暗玉色与墨黑主色，低饱和金色点缀，国风水墨质感，电影级侧后方自然光，雾霭轻薄，青黑对比，暗调美学，高对比度，胶片质感，写实如幻境，横版16:9，无文字水印
```

Negative:

```text
不要仙侠游戏感，不要科技机甲，不要过度粒子特效，不要营销海报感，不要明亮糖果色，不要文字水印
```

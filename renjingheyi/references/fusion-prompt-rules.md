# 多图融合约束提示词模板（Fusion Prompt Rules）

人景合一的提示词 = **07 主提示词（原样）** + **固定融合约束（追加）**。原始画面描述一字不改。

## 融合约束模板

把下面这段追加在 07 主提示词之后（中文，供 gpt-image-2 等多参考图模型理解参考图角色）：

```text
【多图融合约束】
- 以参考图中的人物为身份基准：保持五官、脸型、发型、年龄段、服装、配饰与人物三视图参考完全一致，不改变识别特征。
- 以参考图中的场景为环境基准：保持空间布局、墙体门窗、家具陈设、材质与场景定版参考一致，只按本镜光线/时段/天气呈现。
- 以参考图中的道具为道具基准：关键道具外形、材质、年代与道具定版参考一致。
- 按本镜景别构图：<景别>，<运镜对应的取景>。
- 画面只呈现可见内容，不画台词、字幕、镜号、心理活动。
- 竖屏 9:16，真实人物画风，民俗年代质感，低饱和，电影感光影。
- 无文字，无水印，无logo，不使用明星脸，不使用真实人物肖像。
```

`<景别>`/`<运镜>` 由 manifest 的 `shot` 字段填入。多参考图时，按 `--image` 传入顺序在约束里点明「第1张为人物、第2张为场景、第3张为道具」可提升模型理解（不同模型支持度不同，作为增强项）。

## 运镜 → 静帧取景映射

镜头图是静帧，把运镜翻译成可见构图：

```text
固定镜头     → 稳定居中构图
轻微推进     → 主体略大、前景强调
轻微后拉     → 环境更多入画
平移/跟拍    → 主体偏画面一侧，留出运动方向空间
切到特写     → 主体面部/道具占主导
俯拍         → 高角度俯视
仰拍         → 低角度仰视
```

## 负面提示词

- 优先用 manifest 的 `negative`（来自 07 统一负面提示词）。
- gpt-image-2（OpenAI 兼容 edits 端点）不单独吃 negative 字段时，把关键禁止项并进融合约束末尾（已含「无文字/无水印/不用明星脸」）。
- SD/ComfyUI 等支持 negative 的平台，单独传 `negative`。

## 多候选与一致性

- 每镜默认出 2-4 候选（`--n`），网页选最一致的一张。
- 一致性不达标时的调整顺序：① 换更接近的人物三视图参考；② 在约束里强化「保持与参考一致」；③ 降低画面复杂度（减道具/简化动作）；④ 重出。
- 不要靠改 07 主提示词救一致性——那是 `storyboard-image-prompts` 的职责。

## 成本与风险（每次实跑前说明）

- 估算：镜头数 × 候选数 = 总调用次数，多图 edits 比纯文生图更贵。
- 人物/场景/道具参考图会上传第三方，提醒原创素材泄露风险。
- 未授权时一律 `--dry-run`，只打印命令和参考图清单。

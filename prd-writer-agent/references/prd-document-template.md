> 适用于用 AI 参与开发的项目。项目启动前先估算成本和产出，执行过程中记录实际 token、金额和交付物，结束后对比预估与实际，并为后期计算 ROI 保留收益口径。不要编造数据；缺失时标记为 `待估算`、`待统计` 或 `待确认`。

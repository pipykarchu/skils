# 漫剧生产工作流总控

## 定位

把一个漫剧想法推进成可生产的项目文件，包括 PRD、生产 SOP、角色档案、分集大纲、剧本、分镜表、AI 生图提示词和质检清单。

本 skill 是总控，不替代专业子 skill：

- 用 `prd-writer-agent` 定义项目方向和验收标准。
- 用 `screenplay-director` 写故事、人物、剧本和 Word/Markdown 文件。
- 用 `script-to-storyboard` 拆分镜、生成 Excel/Markdown 分镜表和 AI 生图提示词。

## 默认规则

- 默认中文。
- 先用大白话说明当前阶段目的，再执行具体操作。
- 涉及写入文件、运行命令、调用外部 API 或上传素材前，先说明风险。
- 不主动调用外部 API；除非用户明确要求，并确认会消耗额度、内容会发送到第三方。
- 保护原创内容：提醒用户剧本、人设、角色图、LoRA 训练图上传外部平台有泄露风险。
- 已有项目文件优先复用，不覆盖用户原稿；需要改动时追加版本或时间戳。
- 每次只推进一个明确阶段，阶段完成后给出下一步建议和成功标志。

## 快速入口

当用户说“启动漫剧项目”“做一套漫剧工作流”“从 PRD 到分镜”“批量做第 N 集”“整理漫剧项目文件夹”时，启动本流程。

若信息不足，只问最多 3 个问题：

- 项目名或临时标题是什么？
- 当前处于哪个阶段：想法、PRD、剧本、分镜、提示词、成片检查？
- 已有素材在哪里：故事文本、剧本文件、角色设定、PRD、Word/PDF/Markdown？

## 项目目录

新项目默认在当前工作区创建：

```text
<项目名>/
  00_PRD/
  01_生产SOP/
  02_世界观/
  03_角色设定/
  04_分集大纲/
  05_剧本/
  06_分镜表/
  07_绘图提示词/
  08_成片检查/
  09_素材与参考/
```

同时维护：

```text
<项目名>/项目状态.md
```

`项目状态.md` 至少记录：

- 项目名
- 当前阶段
- 已完成文件
- 待确认项
- 下一步
- 最近一次更新时间

## 阶段流程

### 阶段 1：项目定义

调用 `prd-writer-agent`。

目的：定义“这部漫剧要做成什么样”，不是写软件功能。

输入：

- 题材
- 目标观众
- 主角人设
- 爽点类型
- 集数
- 每集时长
- 画风
- 输出格式
- 禁止内容
- 成功标准

输出到：

```text
<项目名>/00_PRD/<项目名>_PRD.md
<项目名>/00_PRD/<项目名>_PRD.html
```

成功标志：

- 能一眼看懂题材、观众、主角、爽点、集数、画风和验收标准。
- “本版不做”和风险项明确。
- 用户确认方向后再进入剧本阶段。

### 阶段 2：生产 SOP

本 skill 直接生成或维护 SOP。

输出到：

```text
<项目名>/01_生产SOP/<项目名>_漫剧生产SOP.md
```

SOP 必须包含：

- 选题
- 人设
- 分集大纲
- 单集剧本
- 分镜
- AI 生图提示词
- 配音文案
- 字幕
- 质检
- 发布

每一步写清：

- 输入
- 操作
- 输出
- 检查标准
- 常见错误

成功标志：

- 之后每一集都能按同一套步骤生产。
- 新人或外包能照着做。

### 阶段 3：角色与剧本

调用 `screenplay-director`。

目的：把故事、梗概、小说片段或 PRD 转成可拍、可分镜、可生图的中文剧本。

输出到：

```text
<项目名>/03_角色设定/角色档案.md
<项目名>/03_角色设定/角色固定提示词.md
<项目名>/04_分集大纲/<项目名>_分集大纲.md
<项目名>/05_剧本/第XX集_<标题>.md
<项目名>/05_剧本/第XX集_<标题>.docx
```

角色档案必须包含：

- 年龄
- 身份
- 外貌
- 发型
- 服装
- 性格
- 口头禅
- 情绪表达
- 人物目标
- 人物弱点
- 与其他角色关系
- 绘图固定提示词
- 禁止变化

成功标志：

- 女主、男主、反派每次出场有稳定描述。
- 每个剧本片段有明确戏剧功能。
- 每个片段可拆成镜头，不靠抽象旁白推动。

### 阶段 4：剧本转分镜

调用 `script-to-storyboard`。

目的：把剧本拆成镜头级分镜表，并生成 AI 生图提示词。

输入优先级：

1. 指定剧本文件和片段名称。
2. 若未指定片段，使用整集剧本。
3. 若存在 `03_角色设定/角色档案.md`，要求分镜提示词沿用角色固定描述。

输出到：

```text
<项目名>/06_分镜表/第XX集_分镜脚本.md
<项目名>/06_分镜表/第XX集_分镜脚本.xlsx
<项目名>/07_绘图提示词/第XX集_生图提示词.md
```

每个镜头至少包含：

- 镜号
- 时长
- 景别
- 场景
- 时间
- 出场事物造型
- 画面描述
- 运镜
- 对白
- 音效
- AI 生图提示词
- 负面提示词
- 备注

成功标志：

- 每个镜头可以直接拿去生成图。
- 提示词不把对白、心理活动、抽象情绪硬塞进画面。
- 角色外貌、发型、服装、关键识别点稳定。

### 阶段 5：生图准备

本 skill 负责把分镜表整理成绘图平台可用提示词包。

按目标平台整理：

- LiblibAI：中文说明 + 正向提示词 + 负向提示词。
- ComfyUI/SDXL：英文 prompt + negative prompt + 画幅 + seed 备注。
- Midjourney：单行画面描述 + 风格控制 + 画幅参数。

提示词检查：

- 主体明确。
- 景别明确。
- 角色固定描述完整。
- 场景和时间可见。
- 没有混入不可见心理描写。
- 有画面质量词：清晰构图、主体明确、电影感灯光、细节完整、无文字水印、横版 16:9。

### 阶段 6：质检

输出到：

```text
<项目名>/08_成片检查/第XX集_质检.md
```

检查项：

- 人物设定是否前后矛盾。
- 剧情节奏是否拖沓。
- 爽点是否够强。
- 前 3 秒钩子是否清楚。
- 每集结尾是否有追更动力。
- 镜头是否能画出来。
- 台词是否适合短视频。
- 提示词是否保持角色一致。
- 是否存在版权、平台审核或素材泄露风险。

## 常用调用方式

从零启动：

```text
$manju-production-workflow 启动漫剧项目《重生后我不再忍了》，题材都市复仇，30集，每集60秒，韩漫感，短视频连载。
```

只做第 1 集：

```text
$manju-production-workflow 根据已有 PRD 和角色设定，生成第1集剧本，再拆成分镜表和生图提示词。
```

继续生产后续集：

```text
$manju-production-workflow 继续做第2集，沿用第1集角色档案、画风和分镜格式。
```

检查项目：

```text
$manju-production-workflow 检查第1集剧本、分镜和生图提示词是否一致。
```

## 与子 skill 的交接规则

- 交给 `prd-writer-agent` 前，提供项目名、题材、目标观众、集数、每集时长、画风、输出格式和成功标准。
- 交给 `screenplay-director` 前，提供 PRD、角色方向、剧情梗概、目标集数和单集时长。
- 交给 `script-to-storyboard` 前，提供剧本文件路径、片段名称、角色档案路径和输出目录。
- 子 skill 生成文件后，更新 `项目状态.md`。

## 结束输出

每个阶段结束时输出：

- 已完成什么
- 文件保存在哪里
- 是否有待确认项
- 下一步该调用哪个 skill
- 成功标志是否达成

# 发布文档模板结构速查

## 发布检查清单结构
1. 发布基本信息（版本号、包名、SDK、签名）
2. 门禁状态（D1-D6 Gate Check + 签核人）
3. 验收结论（模块通过率表 + 关联验收表链接）
4. 发布范围确认（Go/No-Go + 不发布列表含处置方案）
5. 跨平台检查项（Android/iOS逐条 + 权限声明 + 服务端依赖）
6. 配套资产（截图/图标/更新说明/协议页面）
7. 发布策略（灰度计划 + 时间线）
8. 监控与值班（阈值 + 退出条件：24h稳定无P0/P1）
9. 审批签核（产品终审 + 研发 + 中心负责人Release Gate）

## 回滚方案结构
1. 触发条件（5条量化阈值 + 数据来源）
2. 决策链（5步 + 时限，总计≤30min）
3. 回滚方式（Feature Flag / 强制更新指向 / 灰度回退 / 服务端回滚）
4. 回滚验证（4项确认清单）
5. 通知模板（内部飞书群 + 用户通知）
6. 演练记录（发布前必须完成至少1次）

## 发布执行计划结构
1. 发布概述（平台/版本/窗口/负责人）
2. 验收摘要（通过率数据）
3. 发布范围 + 不发布（含已知限制）
4. Go/No-Go Checklist（≥10项 + 决策点T-1）
5. 灰度计划（内部→20%→全量）
6. 回滚标准（崩溃率/连接率/超时率/投诉）
7. 时间线（T-2到T+7）
8. 监控值班（72h内15min响应）
9. 已知风险与缓解
10. 发布后行动

## 跨平台发版清单结构
1. 版本信息总览（双平台对比表）
2. Android（构建配置/发布渠道/权限声明/特殊检查10项）
3. iOS（构建配置/发布渠道/Info.plist权限/特殊检查）
4. 服务端依赖确认
5. 配套资产清单
6. 版本更新说明（中/英草稿）
7. 发版前最终确认（双平台10项）

# 配置指南

## 1. 墨刀MCP接入

在 Hermes 中执行：
```powershell
hermes config set mcp_servers.modao.url "https://modao.cc/agent-py/ai/mcp"
hermes config set mcp_servers.modao.headers.modao-token "你的墨刀MCP令牌"
```

验证连接：
```powershell
hermes mcp test modao
# 预期输出：✓ Connected, ✓ Tools discovered: 7
```

**获取令牌：** 墨刀网页端 → 头像 → AI设置 → MCP令牌（当前仅个人空间）

## 2. lark-cli授权

```powershell
lark-cli auth login
```

验证：
```powershell
lark-cli docs +fetch --doc <任意文档token> --doc-format markdown --as user
```

## 3. 验证完整链路

1. 准备一个飞书PRD文档URL
2. 在Hermes对话中说："帮我把这个飞书PRD生成墨刀原型 <URL>"
3. 检查是否返回预览链接
4. 在浏览器中打开预览确认效果

## 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| MCP 401 Unauthorized | 令牌无效或过期 | 重新在墨刀获取令牌 |
| lark-cli permission denied | 无文档读取权限 | 确认文档已分享或用user身份 |
| 生成结果在个人空间 | MCP限制 | 手动移到团队空间 |
| 积分不足 | 墨刀AI积分耗尽 | 在墨刀充值或等待刷新 |
